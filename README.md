# حاسبة التكلفة الكمركية — Iraq Customs Calculator

تطبيق سطح مكتب شخصي (Electron) لحساب التكلفة الكمركية في العراق وفق تعرفة الكمارك 2026. يعمل دون إنترنت، وبرعاية **FYY Nexus**.

A personal offline Windows desktop calculator for Iraqi customs costs based on the 2026 tariff (8,381 HS codes). Electron + plain HTML/CSS/JS — no framework at runtime.

## المزايا

- **رمز البند (HS Code):** إدخال 8 أرقام يطابق أحد رموز تعرفة 2026 ويملأ نسبة الرسم والأمانات تلقائياً، مع تنبيه للرموز المحظورة.
- **الإعفاء:** إعفاء الغذاء والأدوية (منذ 7 تشرين الأول 2026) يُطبَّق فقط على الرموز المشمولة — لا يُفرض على جميع الرموز، ولا يشمل التبغ أو المشروبات الكحولية.
- **الحساب:** القيمة الكمركية CIF (العرض + الشحن + التأمين + مصاريف أخرى − الخصومات)، الرسم الكمركي، الأمانات الضريبية، ضريبة المبيعات، رسوم الخدمات، والتحويل إلى الدينار بسعر صرف قابل للتعديل.
- **واجهة عربية RTL** من صفحة واحدة، شاشة بداية برعاية FYY Nexus، تسجيل خروج، وتفريغ الحقول.
- **تبويب المصادر** يوضح أساس الأرقام والمراجع.

## البيانات والمصادر

- نسب الرسم والأمانات لكل رمز: [تعرفة الكمارك 2026 — tariffs.gcc.iq](https://tariffs.gcc.iq/)
- قانون الكمارك رقم (23) لسنة 1984 المعدل
- قرار مجلس الوزراء (569) لسنة 2025 — آليات احتساب القيمة الكمركية
- قرار مجلس الوزراء (957) لسنة 2025 — الأمانات الضريبية
- تعليمات إعفاء الغذاء والدواء منذ 7 تشرين الأول 2026 (خريطة الإعفاء داخل التطبيق محلية لكل رمز)

> أداة شخصية استرشادية، وليست جهة حكومية. القيم النهائية حسب تعليمات الهيئة العامة للكمارك.

## التشغيل

المصدر في `app_src/` والملف الرئيسي `app_src/electron/main.cjs`.

```bash
cd app_src
npx --yes electron@43 .
```

> ملاحظة: `app_src/package.json` يحتوي على تبعيات قالب ويب غير مستخدمة من بداية المشروع؛ التطبيق الفعلي لا يحتاج سواها. لا حاجة إلى `npm install` كامل لتشغيل التطبيق.

## بناء نسخة Windows

```bash
npx --yes @electron/packager app_src IraqCustomsCalculator \
  --platform=win32 --arch=x64 \
  --icon=app_src/desktop/assets/fyy.ico \
  --overwrite --out=build
```

النسخة المبنية كبيرة (~356MB) ولا تُرفع داخل المستودع؛ تُوزَّع كملف مضغوط في GitHub Releases عند الحاجة.

## بنية المشروع

```
app_src/
  desktop/        واجهة التطبيق (index.html، tariff.json، الأصول)
  electron/       عملية Electron الرئيسية
```
